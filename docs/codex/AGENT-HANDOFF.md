- **Authority:** read-only or approved-write; scope and file ownership
- **Verified findings:** include paths/lines and sources
- **Assumptions / unknowns:**
- **Changes made:** exact files; or “none”
- **Tests:** commands, environment, passed/failed/skipped/not run
- **Risks / compatibility:**
- **Conflicts or dependencies:**
- **Approval needed:** action and rationale
- **Recommendation / next step:**

- **Project knowledge impact:** relevant architecture findings, ADR candidates, glossary changes, current-state changes or player-facing changelog candidates with evidence; otherwise “None”. Recommend only; coordinator integrates.
